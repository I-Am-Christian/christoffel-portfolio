# Christoffel du Toit Portfolio

A responsive GitHub Pages portfolio for Christoffel du Toit.

## Files
- `index.html` — page structure/content
- `styles.css` — responsive styling
- `script.js` — mobile hamburger navigation
- `assets/profile.jpg` — profile image

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Go to Settings → Pages.
4. Set the source to the main branch and root folder.
5. Save and open the generated GitHub Pages URL.

The site is designed mobile-first with a responsive navigation menu.
